# Token frugality — the first principle

Every token in a skill, reference, agent brief, or status line is paid **on every run, by
every user, forever**. One wasted token compounds over millions of runs. So: say it once, say
it short, then stop.

In priority order:

- **Inline excerpts, never whole files** ([executor-brief.md](./executor-brief.md)).
- **One status line per transition, never a paragraph** ([run-status.md](./run-status.md)).
- **Every agent returns a fixed few lines or a schema**, never free prose
  ([schemas.md](./schemas.md)).
- **State each fact once.** Don't restate it across files — link instead.
- **Cut throat-clearing and hedges** ("it's important to note", "in order to", "basically",
  "simply", "of course").
- **An example earns its length** only by teaching something the prose can't.

If a sentence can go without losing meaning, it's already gone.
